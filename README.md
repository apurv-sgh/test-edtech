# Zegnite- Edtech

A modern EdTech platform repository containing both frontend and backend code with Student+ Counsellor +Industry_Expert domains.[Integrated & Functional].

## 📁 File Structure

```
.
├── .vscode/                 # VS Code workspace settings
├── backend/                 # Backend server source code
├── frontend/                # Frontend application source code
├── PAYMENT_INTEGRATION.md   # Payment integration documentation
└── README.md                # Project overview and setup instructions
```

## 🚀 Getting Started

### 1. Clone the Repository & change directory.

### 2. Project Structure

- `frontend/`: Contains all code related to the user-facing web application.
- `backend/`: Contains API, server logic, and database interactions.
- `.vscode/`: Editor-specific configurations (optional).
- `PAYMENT_INTEGRATION.md`: Details for integrating payment gateways.

### 3. Setup Instructions

#### Backend

```sh
cd backend/server
# Install dependencies
npm install
# Start the server
npm run dev
```

#### Frontend

```sh
cd frontend
# Install dependencies
npm install
# Start the development server
npm run dev
```

*Adjust the commands above if your project uses Yarn or another package manager.*

## 📄 Essential Data

- **Payment Integration**: See [PAYMENT_INTEGRATION.md](./PAYMENT_INTEGRATION.md) for instructions.
- **Environment Variables**: Configure environment variables in`backend` as required for your setup, since the app is in Development phase.
